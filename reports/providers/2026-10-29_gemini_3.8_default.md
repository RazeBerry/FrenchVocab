# Gemini 3.8 Flash becomes the default

Evidence, 2026-10-29. Never edited after landing; a correction is a new dated
report that links this one. Moved verbatim from `AGENTS.md` by the 2026-10-31
knowledge sweep.

Gemini defaults to the stable `gemini-3.8-flash` model, selected on 2026-10-29 at the user's request for both local and VM use. The VM sets `VOCABBUILDER_GEMINI_MODEL` in `/etc/vocabbuilder/mobile.env` so the mobile service and legacy remote CLI agree even before a source deployment. The Gemini 3.7 SDK and prompt-panel measurements below are historical and do not measure 3.8. Its generation config uses thinking levels and omits deprecated sampling parameters (`temperature`, `top_p`, and `top_k`) that current Gemini models no longer support.
